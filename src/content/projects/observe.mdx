Observe is a demo LLM/agent observability dashboard, built as the flagship consumer of my own Cedar design system and as a way to demonstrate my UI and motion craft. The domain is chosen deliberately: streaming is native to the data, so the modern-React demos are real rather than contrived, and an agent trace is a literal waterfall — the loading choreography and the data visualisation turn out to be the same shape.

The thesis of the piece is that the choreography of data _arriving_ is craft worth foregrounding. Each of the three surfaces demonstrates a distinct loading pattern inside a persistent dashboard shell: an **Overview** of RSC-streamed aggregates whose per-widget Suspense boundaries resolve in a deliberately tuned order so you read the most important numbers first; a **live feed** — a virtualised table that appends new runs over SSE with one optimistic mutation; and a **trace detail** span waterfall that draws in as the trace "executes," with token-by-token streaming in the message panel, opened as a shared-element overlay and deep-linkable as a full page. Skeletons occupy the exact final size, so content fades in without anything shifting under your eyes.

All the data is mocked by a seeded, deterministic generator feeding Next route handlers with tuned latencies — so the demo is reproducible and the resolution _order_ is itself a design decision, and the same generator backs the tests and Storybook.
